# 风险等级标准（riskLevel）

> 本文件为**统一风险等级标准段**，是所有检测提示词（C++ / TS / 蓝图）的风险等级唯一权威来源。
> 各提示词文件内联了本标准的执行副本，二者须保持一致；修改标准时请同步更新本文件与各提示词副本。
>
> 每个缺陷**必须**输出 `riskLevel` 字段，取值严格限定为：**P0 / P1 / P2 / P3 / Info**。
> 历史上出现过的 `P4` 统一并入 `Info`；**禁止**使用其他等级名称或自创等级（如 S0/S1、紧急/一般 等）。

## 一、等级定义

| 等级 | 含义 | 典型表现 |
|------|------|----------|
| **P0** | 阻断性缺陷：运行时必然或极易触发严重后果 | 崩溃、空引用解引用、数据损坏、安全越权/注入、网络同步致命错误、条件编译失效 |
| **P1** | 明确的正确性 / 资源缺陷：特定条件下触发真实故障 | 内存泄漏、状态不同步、事件/回调泄漏、类型断言掩盖错误、数组越界解引用 |
| **P2** | 性能与健壮性隐患：影响体验/可靠性但非直接崩溃 | 不必要的重渲染、未 memo 的回调、大对象深拷贝、未防抖节流、资源未及时释放但不泄漏 |
| **P3** | 可维护性与规范偏离：不直接影响运行正确性 | 命名不一致、重复代码、魔法数字、缺失类型、与项目命名/导出约定不符 |
| **Info** | 建议性提示 / 优化，不构成缺陷 | 可选的最佳实践、可读性建议、非问题的长效规范建议 |

## 二、派生规则（severity × confidence → riskLevel）

当提示词同时输出 `severity`（critical / major / minor / info）与 `confidence`（high / medium / low）时，
`riskLevel` **必须**由二者二维派生，**不得直接任意指定**：

| severity \ confidence | high | medium | low |
|----------------------|------|--------|-----|
| critical | P0 | P0 | P1 |
| major | P1 | P1 | P2 |
| minor | P2 | P3 | P3 |
| info | P3 | Info | Info |

> 未单独输出 `severity` 的语种 / 家族：按"等级定义"中缺陷本质直接定 base 等级，再套用下方置信度护栏。
> 例如 C++ 类目：MEMF/LEAK/ARRAY/SECURITY/NULL 多为 P0–P1；OSRES/STL/COMPILE 多为 P1–P2；PERF/DEPR/CLASS 多为 P2–P3。

## 三、置信度护栏（硬约束）

- **宁降勿升**：拿不准时取更低等级。
- **low confidence 不得为 P0**：`confidence` 为 `low` 时，无论 `severity` 多高，`riskLevel` 不得为 **P0**
  （矩阵已将其定为 critical+low→P1；major/minor/info+low 仍按矩阵，不得臆造 P0 以避免误报污染）。
- 一律基于代码证据判定，禁止臆造等级或夸大影响。
- 解析层会对 `riskLevel` 做归一化：仅接受 `P0/P1/P2/P3/Info`（大小写、首尾空格容错，`P4`→`Info`，其余非法值置空）。

## 四、UE 项目误报硬规则（仅 UE 家族适用）

> 本节为**误报治理第 1 层**的 UE 专用规则，仅注入 `ue4_cpp_prompt` / `ue5_cpp_prompt` / `ue5_blueprint_prompt`，
> 用于抑制本项目（UE4.5~4.6 + ARK 定制引擎）的高频误报。**通用 C++（`cpp_prompt`）与 TS 提示词不引用本节**。
> 各 UE 提示词内联本节执行副本，须与本节约保持同步。

1. **COMPILE 类封禁**：本项目当前可正常构建。禁止输出"必然编译错误/编译失败/无法编译"类结论；凡语法/API 疑虑（引擎版本差异、定制扩展、自定义基类成员）一律转报语义类别（AUTO/CLASS/PERF），`confidence` ≤ Low 并注明"疑似引擎版本/私有扩展差异，需人工确认"。
2. **UObject 零初始化**：UObject 成员由反射/垃圾回收系统零初始化；只对栈上对象或非 UObject 类型报告"未初始化/随机值"。
3. **引擎不变量对象非空**：GEngine / GameMode / GameState / PlayerController / 默认子对象组件等引擎保证存在的对象，不报"可能为空/未判空崩溃"。
4. **继承间 C 风格转换安全**：有继承关系的类型之间的 C 风格强制转换等价于 `static_cast` 语义，不报"偏移错误/崩溃"，除非有确凿证据表明真实类型不符。
5. **浮点除零非崩溃**：UE 关闭 FPU 异常，浮点除零产生 NaN/Inf 而非崩溃；标"NaN 传播"不标"崩溃"。
6. **check() 非缺陷**：`check()` / `ensure()` 是开发期断言，至多 Info，不报缺陷。
7. **WidgetTree 子控件不缺 UPROPERTY**：WidgetTree 持有的子控件由 UMG 系统管理，不缺 UPROPERTY；只有跨对象/跨资源引用才有 GC 风险。
8. **短路求值保护**：`A && A->B` 形式中，`A` 已判空保护后，`A->B` 不报空解引用。
9. **函数返回指针即调成员低风险**：函数返回指针后直接调用其成员（跨项目通用写法）默认 P3，不报 P0/P1。
